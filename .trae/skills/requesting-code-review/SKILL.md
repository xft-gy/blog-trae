# Requesting Code Review

This skill activates between tasks to review code against the plan and report issues by severity. Critical issues block progress until resolved.

## Usage

1. **Review code**: Examine code against the plan
2. **Identify issues**: Find discrepancies and problems
3. **Classify severity**: Categorize issues by importance
4. **Report findings**: Present issues to the user
5. **Block on criticals**: Stop progress for critical issues
6. **Proceed with minors**: Continue with minor issues noted
