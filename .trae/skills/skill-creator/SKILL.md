# Skill Creator

This skill creates new skills following best practices, including testing methodology. It drops ANTHROPIC_API_KEY requirement from description operations.

## Usage

1. **Define skill purpose**: Clearly state what the skill does and when to invoke it
2. **Follow structure**: Use the required SKILL.md format
3. **Include frontmatter**: Add name and description fields
4. **Write detailed content**: Provide usage guidelines and examples
5. **Test the skill**: Ensure it works as expected
6. **Document thoroughly**: Include all necessary information
