# Subagent-Driven Development

This skill activates with an approved plan to dispatch a fresh subagent per task with two-stage review (spec compliance, then code quality).

## Usage

1. **Dispatch subagents**: Assign each task to a fresh subagent
2. **First-stage review**: Check for spec compliance
3. **Second-stage review**: Evaluate code quality
4. **Iterate as needed**: Request changes if necessary
5. **Merge results**: Combine completed tasks
6. **Verify integration**: Ensure all parts work together
