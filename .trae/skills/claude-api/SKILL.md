# Claude API

This skill interacts with the Claude API to call Claude models for various tasks.

## Usage

1. **Define API task**: Specify the task for Claude API
2. **Set parameters**: Configure API parameters and options
3. **Make API call**: Invoke the Claude API
4. **Process response**: Handle the API response
5. **Use results**: Apply the API results to your task
