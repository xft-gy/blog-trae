# Slack GIF Creator

This skill creates GIFs specifically for use in Slack.

## Usage

1. **Define GIF needs**: Specify the GIF requirements for Slack
2. **Set parameters**: Configure GIF details like size, duration, and content
3. **Create GIF**: Generate the Slack-compatible GIF
4. **Review results**: Examine the created GIF
5. **Share to Slack**: Prepare the GIF for Slack sharing
