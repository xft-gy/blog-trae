# XLSX

This skill processes XLSX spreadsheets for various tasks.

## Usage

1. **Define XLSX task**: Specify the task for working with XLSX files
2. **Upload spreadsheet**: Provide the XLSX file
3. **Process spreadsheet**: Perform the requested operation
4. **Review results**: Examine the processed spreadsheet
5. **Download output**: Get the modified XLSX file
