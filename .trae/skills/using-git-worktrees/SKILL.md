# Using Git Worktrees

This skill activates after design approval to create an isolated workspace on a new branch, run project setup, and verify a clean test baseline.

## Usage

1. **Create new branch**: Create a new branch for the feature or fix
2. **Set up worktree**: Create an isolated workspace
3. **Run setup**: Install dependencies and configure the project
4. **Verify baseline**: Run tests to ensure a clean starting point
5. **Ready for implementation**: The workspace is ready for code changes
