# Executing Plans

This skill activates with an approved plan to execute tasks in batches with human checkpoints. It ensures progress is tracked and verified at key points.

## Usage

1. **Batch tasks**: Group related tasks together
2. **Execute batches**: Run tasks in sequence
3. **Human checkpoints**: Pause at key points for user review
4. **Track progress**: Monitor completion of tasks
5. **Adjust as needed**: Modify plan based on feedback
