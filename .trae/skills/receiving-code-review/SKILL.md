# Receiving Code Review

This skill handles responding to code review feedback, ensuring that all comments are addressed appropriately.

## Usage

1. **Review feedback**: Read all code review comments
2. **Prioritize issues**: Address critical issues first
3. **Make changes**: Implement requested modifications
4. **Document changes**: Explain how feedback was addressed
5. **Resubmit for review**: Send updated code for another review
6. **Close comments**: Mark resolved issues as closed
