# DOCX

This skill processes DOCX documents for various tasks.

## Usage

1. **Define DOCX task**: Specify the task for working with DOCX files
2. **Upload document**: Provide the DOCX file
3. **Process document**: Perform the requested operation
4. **Review results**: Examine the processed document
5. **Download output**: Get the modified DOCX file
