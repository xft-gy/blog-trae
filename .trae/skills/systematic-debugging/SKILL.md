# Systematic Debugging

This skill provides a 4-phase root cause analysis process for systematic debugging. It includes techniques for root-cause-tracing, defense-in-depth, and condition-based-waiting.

## 4-Phase Process

1. **Identify the problem**: Clearly define the issue
2. **Root cause analysis**: Trace the problem to its source
3. **Implement fix**: Apply a solution with defense-in-depth
4. **Verify fix**: Ensure the problem is resolved

## Techniques

- **Root-cause-tracing**: Follow the execution flow to identify the source
- **Defense-in-depth**: Implement multiple layers of protection
- **Condition-based-waiting**: Use appropriate waiting strategies for asynchronous operations
