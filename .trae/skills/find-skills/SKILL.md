# Find Skills

This skill helps users find skills from various sources, including GitHub repositories and skill marketplaces.

## Usage

1. **Define skill needs**: Specify the type of skills you're looking for
2. **Search sources**: Look for skills in repositories and marketplaces
3. **Filter results**: Narrow down based on relevance and quality
4. **Review options**: Examine the found skills
5. **Install selected**: Get instructions for installing the desired skills
