# Writing Plans

This skill activates with approved design to break work into bite-sized tasks (2-5 minutes each). Every task includes exact file paths, complete code, and verification steps.

## Usage

1. **Break down work**: Divide the project into small, manageable tasks
2. **Define tasks**: For each task, specify:
   - Exact file paths
   - Complete code to write
   - Verification steps
3. **Estimate time**: Each task should take 2-5 minutes
4. **Prioritize tasks**: Order tasks logically
5. **Present plan**: Share the plan with the user for approval
