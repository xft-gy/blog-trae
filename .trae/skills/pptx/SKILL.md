# PPTX

This skill processes PPTX presentations for various tasks.

## Usage

1. **Define PPTX task**: Specify the task for working with PPTX files
2. **Upload presentation**: Provide the PPTX file
3. **Process presentation**: Perform the requested operation
4. **Review results**: Examine the processed presentation
5. **Download output**: Get the modified PPTX file
