# PDF

This skill processes PDF documents for various tasks.

## Usage

1. **Define PDF task**: Specify the task for working with PDF files
2. **Upload document**: Provide the PDF file
3. **Process document**: Perform the requested operation
4. **Review results**: Examine the processed PDF
5. **Download output**: Get the modified PDF file
