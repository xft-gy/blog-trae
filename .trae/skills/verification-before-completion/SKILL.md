# Verification Before Completion

This skill ensures that issues are actually fixed before marking them as complete. It provides a structured approach to verify the effectiveness of fixes.

## Usage

1. **Test the fix**: Run relevant tests to verify the issue is resolved
2. **Regression testing**: Ensure no new issues are introduced
3. **Edge case testing**: Test boundary conditions
4. **Documentation**: Update documentation if necessary
5. **Sign-off**: Confirm the fix is complete
