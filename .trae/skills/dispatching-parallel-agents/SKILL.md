# Dispatching Parallel Agents

This skill manages concurrent subagent workflows to parallelize tasks and improve efficiency.

## Usage

1. **Identify parallel tasks**: Determine which tasks can be run concurrently
2. **Dispatch subagents**: Assign tasks to separate subagents
3. **Coordinate work**: Manage communication between subagents
4. **Synchronize results**: Combine results from parallel tasks
5. **Verify completion**: Ensure all tasks are completed successfully
