# Brainstorming

This skill activates before writing code to refine rough ideas through questions, explore alternatives, and present design in sections for validation. It saves the design document for reference.

## Usage

1. **Ask clarifying questions**: Understand the user's goals and requirements
2. **Explore alternatives**: Consider different approaches and technologies
3. **Present design sections**: Break down the design into manageable chunks
4. **Validate with user**: Get feedback on each section
5. **Save design document**: Store the final design for reference
